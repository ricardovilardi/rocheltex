Proceso

De residuo textil a lámina de composite termoestable.

Nueve fases controladas transforman el residuo textil recuperado en un material compuesto termoestable de alto rendimiento, listo para aplicaciones industriales exigentes.

01 02 03 04 05 06 07 08 09
01

Recepción del residuo textil

El proceso comienza con la llegada del residuo textil a planta, clasificado y listo para su transformación.

02

Garneteado

Máquinas garnett abren y deshilachan el residuo, separando el tejido en fibras individuales.

03

Borra

El resultado es borra: fibra textil regenerada, materia prima para las siguientes fases del proceso.

04

Cardado

La borra se carda para alinear y homogeneizar las fibras.

05

Velo cardado

El cardado produce un velo continuo de fibra, la base para el laminado posterior.

06

Aplicación de resina epoxi

Se aplica resina epoxi sobre el velo cardado para preparar la consolidación del material.

07

Laminado del velo cardado

Varias capas de velo impregnado se laminan entre sí para formar el conjunto final.

08

Moldeo por compresión

El laminado se conforma bajo presión y temperatura mediante moldeo por compresión.

09

Lámina de composite termoestable

El resultado es una lámina de material compuesto termoestable, lista para su aplicación industrial.
